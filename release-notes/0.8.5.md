# Call Bots 0.8.5

- Smaller Mac updates: Call Bots now downloads a signed patch containing the changed content when one is available. The full installer remains available for first installations and as a fallback.
- Google Meet bots now have live outgoing volume controls on Mac and Linux. Click a bot's speaker icon or **Volume** in the all-bots bar to adjust 0–200%, independently of microphone mute.
- Anonymous Google Meet bots can now run on Linux servers using the included Ubuntu container and a private virtual display, with audio, video, screen sharing, thumbnails, and stream statistics.
- Mac Meet bots use a private bundled Chrome for Testing browser. Their windows stay visible by default, with **Hide windows / Show windows** available when needed.

Existing installations can use **Call Bots → Check for Updates…**. Version 0.8.3 keeps its existing upgrade to 0.8.4 before receiving newer updates.

## По-русски

- Обновления Mac стали меньше: при наличии подходящего подписанного патча скачивается только изменённое содержимое. Полный установщик остаётся для первой установки и резервной загрузки.
- У ботов Google Meet появилась регулировка исходящей громкости на Mac и Linux. Нажмите значок динамика у бота или **Volume** для всех ботов и выберите уровень 0–200%, независимо от отключения микрофона.
- Анонимные боты Google Meet теперь работают на Linux-серверах в контейнере Ubuntu с виртуальным дисплеем: доступны звук, видео, показ экрана, превью и статистика потоков.
- На Mac боты Meet используют отдельный Chrome for Testing. Окна остаются видимыми по умолчанию; при необходимости доступны **Hide windows / Show windows**.

Для обновления выберите **Call Bots → Check for Updates…**. Версия 0.8.3 сначала обновляется до 0.8.4 через прежний путь совместимости, а затем получает новые версии.
